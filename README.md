### 👨‍💻 About Me

I’m a Computer Science & Engineering undergraduate at **United Institute of Technology, Prayagraj**, with a strong engineering foundation stemming from a background in Mechanical Engineering. I specialize in developing **high-performance full-stack web applications**, **AI/ML-powered threat detection systems**, and **data analytics pipelines**.

- 🛡️ Developing **SecureNet IDS** — An AI-powered Intrusion Detection System achieving **99.56% detection accuracy** using Random Forest trained on CICIDS2017 with live packet capture & interactive telemetry.
- 💻 Building modern web applications using **React, Next.js, Node.js, Express, FastAPI & PostgreSQL**.
- 🤖 Engineering Generative AI workflows with **LLMs, RAG architectures (LangChain, ChromaDB), Gemini API & Hugging Face**.
- 📊 Formulating exploratory data analysis & business intelligence models with **Python, Pandas, Scikit-learn, and Tableau** (Former Data Analyst Intern at **InternAlpha**).
- 🧠 Actively solving Data Structures & Algorithms with **100+ problems solved** on **LeetCode** and **GeeksforGeeks**.
- ✍️ Author & creator of **[ThePathak.tech](https://pathakpk7blog.vercel.app)** — writing technical deep-dives on Frontier AI safety, developer workflows, and system architecture.
